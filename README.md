## Temas previstos / Planned topics

- **Novedades y modelos / AI news and models:** OpenAI, Claude y novedades relevantes.
- **Skills:** importancia de las skills personalizadas, skills específicas por repositorio y su aplicación a tareas críticas.
- **Herramientas / Tools:** GitHub Copilot App, extensión de IA para VS Code y Codebase Memory MCP.
- **Agentes y testing / Agents and testing:** abrir una aplicación, iniciar sesión, probar formularios y detectar o corregir errores; demo pendiente de validar.
- **FinOps:** resultados del estudio de agosto, consumo de créditos y recomendaciones de stack.
- **Uso eficiente / Efficient usage:** coste, tokens, modelos y selección según complejidad de tarea.
- **Microsoft 365 Copilot:** alternativa para tareas no relacionadas con código dentro de la suscripción corporativa.
- **Configuración de modelos / Model configuration:** modo AUTO, modelos disponibles y revisión con Ángel.
- **Buenas prácticas / Best practices:** recomendaciones de la empresa y canal de comunicación.
- **Skills avanzadas / Advanced skills:** custom instructions, prompt files, custom agents y gobierno de skills.
- **Formatos y contexto / Formats and context:** revisión de TOON, JSON y Markdown, además del comportamiento de Copilot en el codebase.
- **Actividades / Activities:** Kahoot y otros minijuegos.
